微软远程桌面（Microsoft Remote Desktop）是微软官方推出的连接 Windows 远程桌面的移动端客户端，有了微软远程桌面app，iOS用户就可以通过iPhone或者iPad来远程控制Windows电脑，完成工作或者协助他人。

微软远程桌面应用凭借 Microsoft 远程桌面应用程序，可以从几乎任何位置连接到远程电脑和用户的工作资源。远程桌面客户端旨在帮助用户在任意位置完成工作。

微软远程桌面iOS版支持 Windows Professional 和 Windows Server 版本。要查看受支持的 Windows 版本的完整列表并成功连接到 Windows 电脑。

功能介绍

\* 通过用户的远程桌面网关访问远程资源

\* 提供支持 Windows 手势和 RemoteFX 的丰富多点触控体验

\* 安全连接用户的数据和应用程序

\* 从连接中心轻松管理所有远程连接

\* 无缝音频和视频流

\* 轻松连接至外部显示器或投影仪以供演示

\* 支持 Azure RemoteApp
