Movable Type是国际上最为流行的BLOG程序，今天安装了一下，感觉安装起来挺麻烦，需要安装PERL的库文件，搞不懂这么流行的程序为什么用CGI来写，难道CGI耗费系统资源少一些吗？据我所知CGI耗费CPU资源可不是一点半点啊。

除了安装PHP，MYSQL，PERL之外还需要去 `http://ppm.activestate.com/PPMPackages/zips/` 下载一个DBD文件来安装PERL的MYSQL驱动，使用 PPM Install c:\temp\DBD.ppd 来安装。初始设定是：1. 执行 mt-check.cgi 来做最后检查，重要是看看支持 MySQL 的套件是否有装上 2. 执行 mt-load.cgi 做初始化 3. 执行 mt.cgi 做初始设定 4. 重建网站所有文件 (rebuild) 4. 删除 mt-load.cgi 文件 5. 架构已成，可做测试了。

装好后运行了一下，发现其工作方式是全部文件都自动生成HTML文件，生成静态文件的好处很多，可以大大减少系统负荷，容易被索引。不好的地方是更新起来较为麻烦，改一篇文章就要重新发布一遍。默认设置下，对于英文标题的BLOG自动会以标题名发布文件，这个功能可真是不错。

简单地看了看，其功能还是很强大的，做一个英文的CMS可以说绰绰有余。可惜的是Movable Type目前已经商业化，免费的版本只能建立一个BLOGER。这大概也是很多BLOGER转向WORD PRESS的原因了。

总的来讲，目前市场上流行的Blogger,Live Jourmal,Typepad从性质上来说是网站提供的“博客服务”，真正的博客程序只有Movable Type和 Word Press，其中Movable Type是基于CGI的，发布静态HTML文件，多用户版是收费的，Word Press是基于PHP的，发布的是动态页面，现在还是免费开源。
