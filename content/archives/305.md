下面是ZBLOG的屏蔽评论中敏感关键字的程序代码，主要用于替换文章评论中的敏感或非法的关键字。

 只需要修改一个文件c\_system\_event.asp，将其中的objComment.Content=Request.Form("inpArticle")修改为objComment.Content=WordFilter(Request.Form("inpArticle"))

然后在c\_system\_event.asp文件尾部加入代码：


Function WordFilter(strInput)　
    Dim i　
    Dim strOutput　
    Dim strFilter　
    strFilter = Split("关键字1,关键字2,关键字3", ",")　
    strOutput = strInput　
    For i = 0 To UBound(strFilter)　
        strOutput = Replace(strOutput, strFilter(i), String(Len(strFilter(i)), "×"))　
    Next　
    WordFilter = strOutput　
End Function
