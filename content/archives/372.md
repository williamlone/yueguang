这是一段很有用的代码，和[绑定多域名的ASP代码](https://www.williamlong.info/archives/201.html)类似，如果你只有一个PHP空间，而你又想放置多个多个站点，下面这些代码可以帮到你。

第一个：

if($HTTP\_HOST=="[www.moon-soft.com](http://www.moon-soft.com)"){  
Header("Location: moon.htm");  
}  
elseif($HTTP\_HOST=="[www.williamlong.info](https://www.williamlong.info)"){  
Header("Location: williamlong.htm");  
}  
else{  
Header("Location: other.htm");  
}

第二个：

if($HTTP\_HOST=="[www.moon-soft.com](http://www.moon-soft.com)"){  
require "moon.htm";  
}  
elseif($HTTP\_HOST=="[www.williamlong.info](https://www.williamlong.info)"){  
require "williamlong.htm";  
}  
else{  
require "other.htm";  
}
