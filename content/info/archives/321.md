JavaScript 是 Web 开发与设计中不可或缺的东西，不管是一个简单的网页还是一个专业的站点，也不管你是高手还是菜鸟，如今 JavaScript 库越来越强大，可以胜任许多复杂的工作，然而同时，人们在众多 JavaScript 库面前又觉得无所适从，本文，我们将使用 Google 搜索出排名前 10 位的 JavaScript 库，并对它们逐一进行介绍。

1. [jQuery: The Write Less, Do More, JavaScript Library](http://jquery.com/)   
jQuery 是一个很新的 JavaScript 库，它的口号是“几行代码，能干大事”（Write Less, Do More），它是拥有最多插件和扩展的 JavaScript 库，以下是 jQuery 现状：  
 

- 当前版本： **1.3.2**
- 文件尺寸：压缩后最小19KB，未压缩为120K。
- 作者： [John Resig](http://ejohn.org/)
- [拥有19种语言的教程](http://docs.jquery.com/Tutorials): 教程总计183种。
- [著名用户：](http://docs.jquery.com/Sites_Using_jQuery) 超过1000个
- [插件](http://plugins.jquery.com/): 3493
- 易学
- 对设计师来说非常易学，使用 CSS 语法
- 拥有大量有趣的扩展
- 拥有非常出色的社区，可能是最大的
- 被数以百万的站点使用，包括诸如 Google, Dell, CBS, NBC, DIGG, Bank of America, Wordpress, Drupal, Mozilla 等著名站点。

2. [MooTools – a compact javascript framework](http://mootools.net/)   
MooTools 是一个使用 MIT 许可的开源项目，意味着你可以在任一场合使用或对它就行修改。  
 

- 当前版本: **1.2.3**
- 未压缩尺寸: **95 KB** (客户端) **，22 KB** (服务器端)
- 作者: [Valerio Proietti](http://mad4milk.net/)
- 著名用户: [w3c](http://validator.w3.org/), [cnet](http://cnet.com/), [bing](http://www.bing.com/reference/semhtml/Albert_Einstein?qpvt=albert+einstein&amp;amp;q=albert+einstein&amp;amp;fwd=1), …
- 官方站上的插件数目: 4
- 拥有更好的面向对象结构
- 它的动画效果更平滑
- 语法及对象句柄更富逻辑

3. [Prototype](http://www.prototypejs.org/): Easy Ajax and DOM manipulation for dynamic web applications   
被一些大型媒体公司和组织使用，*Protorype* 是一个很独特的 JavaScript 库，逐渐成为 Web 引用开发者的代码基础，随着最新的 1.6.1 版本的推出，*Protorype* 在性能，用户自定义事件以及同现代浏览器兼容方面越来越完善。  
 

- 最新版本: **1.6.1**
- 未压缩尺寸: **136 KB** (大约5000行代码)
- 作者: [Sam Stephenson](http://twitter.com/sstephenson)
- [著名用户](http://www.prototypejs.org/real-world): NASA, CNN, NBC, …
- 插件数目: [150+](http://scripteka.com/)
- 更适用于大型 Web 程序

4. [Dojo Toolkit](http://www.dojotoolkit.org/): great experiences for everyone   
Dojo 的内核小巧，快，精深，可用来创建反应灵敏的 Web 程序，拥有很出色的 UI 工具，在可访问性，本地化方面也做得很好。  
 

- 最新版本: **1.4 Beta**
- 未压缩尺寸: **26 KB** (约5000行代码)
- 开发组织: [Dojo Foundation](http://dojofoundation.org/)
- [著名用户](http://www.dojotoolkit.org/DojoUsers): AOL, IBM, Sun, …
- 支持客户端数据存储
- 支持服务器端数据存储
- 异步通讯

5. [script.aculo.us](http://script.aculo.us/): easy-to-use, cross-browser user interface JavaScript libraries   
*script.aculo.us* 是一个开源 JavaScript 库，适用于创建视觉效果和 UI 行为，最新版本拥有一些新功能，如创建加载进程，Windows Media 和 Real Media 播放器检查等。  
  
  
 

- 最新版本: **1.8.3** (8 October, 2009)
- 未压缩尺寸: **197 KB** (包含 Prototype 和 测试页)
- 作者: [Thomas Fuchs](http://mir.aculo.us/)
- 著名用户: [Gucci](http://www.gucci.com/), [Feedburner](http://www.feedburner.com/), [Ruby on Rails](http://www.rubyonrails.org/), …
- [Documentation wiki & Usage](http://wiki.github.com/madrobby/scriptaculous) （文档）
- *script.aculo.us* 是对 Prototype 的扩展，增加了视觉效果，UI 控制等功能。

6. [ExtJS](http://www.extjs.com/): Cross-Browser Rich Internet Application Framework   
ExtJS 是一个很出色的跨浏览器 JavaScript 框架，可以用来创建富 Web 应用，支持所有现代浏览器。拥有大量插件和扩展。  
 

- 最新版本: **3.0** (6th July, 2009)
- 压缩后尺寸: **197 KB** (包含 *Prototype* 和测试页)
- 作者: [Jack Slocum](http://jackslocum.com/blog/)
- 著名用户: [Gucci](http://www.gucci.com/), [Feedburner](http://www.feedburner.com/), [Ruby on Rails](http://www.rubyonrails.org/), …
- [Download](http://www.extjs.com/products/extjs/download.php) | [Samples & Demos](http://www.extjs.com/deploy/dev/examples/samples.html) | [API Documentation](http://www.extjs.com/deploy/dev/docs/)
- 拥有很出色的部件和技术支持

7. [UIZE](http://www.uize.com/): supporting widgets, AJAX, DOM, templates, and more   
UIZE 的一些现状：  
- 一个开源 JavaScript 框架  
- 很容易更换 CSS 皮肤  
- 大量内置饰件  
- 令人目眩的效果和强大的功能  
 

- [压缩后的尺寸: **4.47 MB**](http://www.uize.com/uize.zip)
- 作者: [Chris van Rensburg](http://www.tomkidding.com/)

8. [YUI Library](http://developer.yahoo.com/yui/): is proven, scalable, fast, and robust   
YUI 是本列表中规模最宏大的 JavaScript 库，它拥有数不清的强大功能，插件以及扩展，当然要掌握它也需要很长时间。  
 

- 最新版本: **3** (September 2009)
- 整个开发包尺寸: **5.7 MB** (包括源代码，调试文件，示例等)
- 开发公司: [Yahoo! Developer Network](http://developer.yahoo.com/yui/)
- 著名用户: [LinkedIn](http://www.linkedin.com/), [Wikia](http://www.wikia.com/), [NewsVine](http://www.newsvine.com/), …

9. [Archetype](http://archetypejs.org/)   
Archetype 现状：  
 

- 最新版本: **0.10.0** (September 2009)
- 尺寸: **2.14 MB**
- 作者: **Temsa & Swiip**
- 用户: [GifTeer](http://gifteer.com/), [Meteo France](http://france.meteofrance.com/), …

10. [qooxdoo](http://qooxdoo.org/): the new era of web development   
*qooxdoo* 是什么？是一个面向对象 JavaScript 库，包含跨平台开发工具链，顶级 GUI 工具以及高级客户端服务器通讯层，它是一个基于 LGPL/EPL 许可的开源项目：  
 

- 最新版本: **0.8** (September 2009)
- 尺寸: **24 MB**
- 核心开发者: [1&1 Internet AG](http://1and1.com/xml/order/AboutUs)
- [Download](http://qooxdoo.org/download) | [Samples & Demos](http://qooxdoo.org/demo) | [Documentation](http://qooxdoo.org/documentation)
- 完整的 GUI 工具包
- 支持对象间的拖放操作
