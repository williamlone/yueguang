**GENERAL Browsing:** 

**1.** [GoogleTagCloudMaker](http://userscripts.org/scripts/show/6171) **推荐安装。**  
自动在搜索结果的右边生成标签云（tagcloud，覆盖了原来的赞助商广告），鼠标停留在某个标签上，就会把含有此标签的搜索结果显示在最前面。可能我说的不是很清楚，原文也说的不是很清楚。安装一下，你就知道有多好用了。Gfan 必备！支持中文标签云哦。

**2.** [Disable Text Ads](http://userscripts.org/scripts/show/3637)  
自动移除 VibrantMedia(IntelliTXT), Kontera 和 Linkworth  
的内文文字广告。  
  
**3.** [RSS+Atom Feed Subscribe Button Generator](http://userscripts.org/scripts/show/688)  
当你发现一个优秀的新博客时，你还在满屏幕找 RSS 订阅按钮吗？安装这个 addon 之后，你只需在左上角点击自动生成的订阅按钮。（感觉不是很实用，如果有高手会修改这个脚本的话，建议为这个脚本添加更强的功能：订阅到抓虾之类的按钮。）

**4.** [Textarea Backup](http://userscripts.org/scripts/show/7671) **推荐安装。**  
文本框备份。你每按下十个按键、每十秒、文本框失去焦点（就是一闪一闪的竖线状光标在文本框中消失的时候），该 addon 会自动备份一次。当文本成功提交到服务器时，保存的文字会自动删除。**会自动还原的哦**。

**5.** [LookItUp](http://userscripts.org/scripts/show/7715)  
选中网页文字，按下” w “，右边会出现 Wikipedia 中该词的页面。原文说可以自定义，对高手来说可能比较简单。

**6.** [Linkify ting](http://userscripts.org/scripts/show/2254) **推荐安装。**  
自动把一个 URL 地址变成可以点击的链接。

**7.** [Google MP3](http://userscripts.org/scripts/show/6353) **推荐安装。**  
自动调用 Google  MP3 Player 播放任意网页中的 MP3 ，关于 Google MP3 Player 是这样的，Gmail 会自动调用 Google MP3 Player 来播放附件中的 MP3 文件，既然 Gmail 能用这个播放器，我们当然也能拿来用了。详细的介绍请参考 ：[8个圈圈的Blogger - Gmail=MP3播放器？](http://bloooooooogger.blogspot.com/2006/08/gmailmp3.html)

**VIDEO and TRAILERS:**

**8.** [Apple Trailer Download](http://userscripts.org/scripts/show/2484 "download apple trailers")  
让你可以非常方便地从 [movie trailers from apple.com![](http://spa.snap.com/images/v1.22/theme/ice/iconLink.gif)](http://www.apple.com/trailers/ "Apple Movie Trailers") 下载任意大小的视频。用法在你要下载的大小上右键，选择“链接另存为”。update ：关于这个 addon 的用法请看这里：[你看预告片的么？](http://costi.blogbus.com/logs/4777237.html)

**9.** [Download Video](http://userscripts.org/scripts/show/4037 "download video")  
让你轻轻松松得到 YouTube, Google Video, Myspace, Metacafe, Break.com, Putfile, Dailymotion 和 Sevenload 里面的视频的真实地址。只要点击页面顶部黄色的 Get download link(s) to video(s) 就行。

**GMAIL Goodies:****10.** [Gmail Super Clean](http://userscripts.org/scripts/show/7646 "greasemonkey addon for gmail")  
让 Gmail 的界面变成简洁的浅蓝色的 Web 2.0 风格。

 

**11.** [Gmail + Reader Integrator](http://userscripts.org/scripts/show/7435 "integrate google reader into gmail")   
喜欢 Gmail 和 Google Reader 的你怎么可以错过这个在 Gmail 里面看 Google Reader 的 addon ？

**12.** [Gmail Spam-count Hide](http://userscripts.org/scripts/show/2210 "hide gmail spam count")  
隐藏 Gmail 中垃圾邮件的计数。就是传说中眼不见为净的境界。

**SITE SPECIFIC (Youtube, Myspace, Facebook, IMDB, Digg, Last.fm, del.icio.us)****13.** [del.icio.us Prettifier](http://userscripts.org/scripts/show/2631)  
是不是觉得 [del.icio.us](http://del.icio.us/) 的界面很没特色（很难看）？快安装上吧。

 

**14.** [IMDB enlarge actor pictures on hover](http://userscripts.org/scripts/show/4169)  
放大 [IMDB](http://www.imdb.cn/) （电影资料库，这里我链接的是其中文版）中演员的照片。

**15.** [AdSlicer for MySpace](http://userscripts.org/scripts/show/3890 "remove ads from myspace")  
移除 [MySpace](http://myspace.com/) 中的广告和空白。

**16.** [YouTube Googler](http://userscripts.org/scripts/show/6198 "greasemonkey script for Youtube")  
让 [YouTube](http://youtube.com/) 的界面看起来想 [Google Videos](http://video.google.com/) ，看来是某狂热 Gfan 的杰作。

**17.** [Facebook Auto-Colorizer](http://userscripts.org/scripts/show/3626 "greasemonkey script for Facebook")  
[facebook](http://www.facebook.com/) 颜色主题一个。

**18.** [Digg - Add Mirror](http://userscripts.org/scripts/show/7585 "greasemonkey script for Digg")  
在 digg it 按钮下添加这样几个按钮：在 [DuggMirror](http://duggmirror.com/) , Coral Cache, Google Cache 和 Archive.org 中查看该 digg 。当该 digg 的源链接过期，你还是可以轻松地浏览该 digg 的详细内容。也可以当成代理来使用。

**19.** [Last.fm Artist Fan Rank](http://userscripts.org/scripts/show/4729)  
[last.fm](http://lastfm.cn/) 是一个 Web 2.0 音乐分享社区。我安装该 addon 之后，去了 Last.fm 一趟，不知道它到底是用来干嘛的。-\_-|||（我已经修改了该 addon 的作用网页范围。）

**20.** Greasemonkey Addons 安装教程

- 安装 Greasemonkey ：[http://www.greasespot.net](http://www.greasespot.net/ "download greasemonkey")（适合 [firefox](http://portableapps.com/apps/internet/firefox_portable) 用户）
- 重启 firefox
- 进入 Greasemonkey addon 的详细页面。点击 Insrall this script
- 等待 3 秒后，点击弹出窗口中的 Install 按钮。
