微软的IIS是流行网站服务器软件，但和其他平台的整合性还不够，为了和LAMP平台相竞争，微软推出了Microsoft Web Platform这个平台，Microsoft Web Platform不仅仅是一组功能强大的工具、服务器和技术，它还为网站、服务和应用程序的构建和托管提供了一个完整的生态系统。

Microsoft Web Platform是微软 IIS + ASP.NET + SQL Server + Visual Studio 的整合平台，也正是 Apache + PHP + MySQL 的主要竞争对手。Microsoft Web Platform可以对用户的各种组件进行管理、更新，或者下载免费的工具，比如：Visual Web Developer、SQL Server Express。

Microsoft Web Platform网站上也集合许多微软相关的文章、活动、资源、最新消息、与工具等等。因为 Web 环境过于复杂，有时后若要让网站管理员安装好整个环境，倒真的是有点难度，因此网站一开站就推出了一套 Microsoft Web Platform Installer 工具，可以让网站管理员轻松的安装所有网站的执行环境与网站的开发环境，这套集成工具包括许多套件，包含框架、服务器、数据库、工具、大量PHP的特色应用程序（例如WordPress），用户可以一键安装整个网站应用。

点击访问： Microsoft Web Platform网站: `http://www.microsoft.com/web`
