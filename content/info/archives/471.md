Chrome OS发布后，业界评价不一。焦点问题是，和如日中天的Android相比，Chrome OS如何定位？事实上，Google内部的意见也不一致。创始人Sergey Brin似乎对此项目并不感冒。CEO Eric Schmidt的说法是，Chrome OS针对的是有键盘的设备。而Chrome OS的负责人Linus Upson还颇具雄心：“我们会从笔记本起步，然后同时向两个方向（手机和电视）扩展。”也许前微软首席架构师Ray Ozzie的评价更加一针见血：“Google的战略中Android（以app为主）是在赌过去，而Chrome OS（完全基于Web）则是在赌未来。”

但问题是，迅速关闭Wave等动作表明，Google已经走过了浪漫期，它会给面向未来的Chrome OS足够的时间和耐心吗？项目的主要架构师Matthew Papakipos已经跳槽Facebook了。

TechCrunch 12月14日报道，Gmail之父Paul Buchheit已经公开评论Chrome OS前途堪忧：

“预测：ChromeOS将于明年被终止（或是与Android‘合并’）。”

这条评论在FriendFeed上引起了热烈讨论后，他进一步解释：

“因为Chrome OS没有什么用途，是Android系统（可能作出一些小修改来支持非触摸屏的显示器）不能更好满足的”。

随后他似乎还嫌自己贬的不够，补充说：

“我在想：‘这是不是太明显了，根本不需要说出来？’但我随后就看到，人们仍很看重ChromeOS，谷歌不知道为什么居然还出售使用这种系统的设备。”

当然，对Buchheit的言论不以为然的大有人在。其中包括前Oracle副总裁、现任Feedly CEO的Edwin Khodabakchian.他表示，从开发者的角度来看，Google更应该干掉Android，WebOS才大有前途。而TechCrunch的一位读者则引用Buchheit曾经的亲密战友、FriendFeed设计总监Kevin Fox的评论作为回击： “非常明显的答案是，两类设备（桌面PC和手持设备）的用户需求、任务和交互方式都完全不同，采用两种截然不同的操作系统是明智之举。”

还有评论者给出了公式，认为两个系统都是Linux之上加了一些层，因此合并是可能的：

Android = Linux + User Space Layer （Java and Native） + WebKit browser （not Chrome， but has older V8）

Chrome OS = Linux + Chrome

其他有趣的评论还有：Chrome OS是是Google的B计划，如果Oracle纠缠Java知识产权不放而且官司不利，Google可以大推Chrome OS……

Paul Buchheit几年前从谷歌离职并创办了与Twitter功能类似的FriendFeed，后被Facebook收购。他在Facebook供职几年后，于今年10月加盟知名创业孵化公司Y Combinator，任合伙人。
