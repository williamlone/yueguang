作为Firefox普通用户，我不喜欢保存配置文件来升级Firefox，我喜欢把配置、个人资料保存在网上，换电脑换平台都可以很快适应，还有一把云的感觉。

密码管理：lastpass用了就没换过

收藏夹：

【Delicious】功能强大，方便管理，国外速度慢致命

【Xmarks】速度一般，它同步本地书签,但我不想别人也访问我的书签，所以X掉了

【yahoo收藏】功能太弱，快废了

【QQ书签】速度快，不方便搜索，不方便管理，导出无分类

【google书签】速度快，自己的书签搜索结果大乱套 (iGoogle中不能管理)

【有道书签】速度快，搜索方便，节目太google，有点乱

第二步   设置about:config 

> 
> > 关闭Firefox 4.0扩展检查（很重要，不如部分插件提示不能安装）  
> > 
> > > 新建布尔值 extensions.checkCompatibility.4.0b  
> > > 设置为： false  
> > > 
> > 
> > 关闭扩展安装等待  
> > 
> > > 查找：security.dialog\_enable\_delay  
> > > 默认值：2000（以毫秒为单位）  
> > > 修改为：0  
> > > 
> > 
> > 打开点击复制功能  
> > 
> > > 查找：signed.applets.codebase\_principal\_support  
> > > 修改值为：true  
> > > 
> > 
> > 关闭标签组切换时动画（firefox新功能，快捷键Ctrl+E）  
> > 
> > > 查找：browser.panorama.animate\_zoom  
> > > 修改值为：false  
> > > 
> > 
> > 解决下载文件变0字节问题  
> > 
> > > 查找：browser.download.manager.scanWhenDone  
> > > 修改值为：false  
> > > 
> > 
> > 更改临时文件的路径（windows）  
> > 
> > > 新建字符串：browser.cache.disk.parent\_directory  
> > > 值：d:\temp files  
> > > 
> > 
> >
