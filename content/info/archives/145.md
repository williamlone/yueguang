据说某种“留影就走”的旅行方式是被嘲笑的，而现在我对 Del.icio.us 的依赖就像前者对相机的依赖，伟大服务的特点在于人人都会用，问题是你用的是傻瓜机还是单反，下面的十条建议可能对你有帮助：

1、[Del.icio.us Firefox Extension](http://del.icio.us/help/firefox/extension) 或者 [Internet Explorer Extension](http://del.icio.us/help/ie/extension)（略）；  
2、用 [Delwin](http://www.bafio.it/projects/deliwin/) （or [Delibar](http://www.shinyfrog.net/it/software/delibar/) for the Mac）将书签同步到本机上，这样就不用每次都访问 Del.icio.us 的页面了；  
3、多种搜索方式：

```
http://del.icio.us/tag/keyword（关键字）
```

```
http://del.icio.us/tag/keyword+keyword（两个或更多关键字）
```

```
http://del.icio.us/rss/popular/TAGNAME（某类别下最流行的内容）
```
4、在 Google Reader 里加“add to del.icio.us”的按钮，用 [Google Reader + del.icio.us](http://userscripts.org/scripts/show/7957) 这个脚本；  
5、将你的 Tags 组织起来，方法是 “Settings 页面 > bundle tags”，如果你的 Tags 已经混乱到积重难返了，可以尝试用 Tag 搜索，语法是“tag:啥啥啥”；  
6、[Newsmasher](http://userscripts.org/scripts/show/1087) 是这样一个脚本，安装后它在你的浏览器左上角出现“del.icio.us” tag，点击后会弹出一个小框显示 Del.icio.us 用户对当前页面的反馈情况；  
7、使用[收件箱（Indox）](http://del.icio.us/inbox)订阅某个 tag 或者用户的收录，有点像 StumbleUpon；  
8、拓展它的收录对象，不仅仅是有趣的站点（我很多时候都这样），比如书、电影、旅行计划什么都可以；  
9、在你的个人网站发布你的收录，用 [Linkrolls](http://del.icio.us/help/linkrolls) 和 [Tagrolls](http://del.icio.us/help/tagrolls)；  
10、让你的 tag 有点创意，比如如果收录一本重要的书，用“@book”这样的标签就可以把这个 tag 置顶，方便查找；

留言里有个叫做“[Gagan Diesh](http://www.designstamp.com/)”的人又介绍了两种：  
11、将 http://del.icio.us/search/?all=%s 放在你的 Firefox 地址栏里，可以全域搜索关键字了；  
12、使用这个叫 [Magpie](http://stii.za.net/archives/43) 的脚本将你的书签聚合到个人网站上（是不是比 Del.icio.us 提供的更好些？）。
