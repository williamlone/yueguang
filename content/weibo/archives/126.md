今天将家里的电脑操作系统安装为Windows Server 2003，但是安装后我对这个系统的版权问题还存在疑惑，就是我安装的到底是不是正版的操作系统。

我的公司有正版的Windows Server 2003，于是我就借出来，在家里的电脑上进行安装升级，其实我家里电脑的Windows 2000 Server也是从公司借出来的正版安装的。按道理来说，公司购买的Windows Server 2003有一定量的License许可，那么我安装之后应该也算是正版的。Windows的License许可应该没有限制必须在公司使用吧。

不知道我这样安装的操作系统，微软会认为我使用的是正版还是盗版呢。
