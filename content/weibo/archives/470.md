以下总结一些Firefox扩展的开发资源和文档。

[Mozilla 开发者中心的扩展开发专题](http://developer.mozilla.org/en/docs/Extensions)：在里面可以中学习更多关于扩展开发的知识。

[XUL 1.0 规范](http://www.mozilla.org/projects/xul/xul.html)：更多地了解这种基于 XML 的用户界面语言，它可以构建各种富跨平台应用程序。

[XUL 教程](http://developer.mozilla.org/en/docs/XUL_Tutorial)：Mozilla Development Center 提供了非常全面的 XUL 教程

[Getting started with extension development](http://kb.mozillazine.org/Getting_started_with_extension_development) ：编写一个最简单的Firefox扩展

[Setting up extension development environment](http://developer.mozilla.org/en/docs/Setting_up_extension_development_environment) ：设置一个简单的Firefox扩展

[实战 Firefox 扩展开发](http://www.ibm.com/developerworks/cn/web/wa-lo-firefox-ext/) ：以一个能够批量下载某个 HTML 页面上所有图片的 Firefox 扩展作为案例，详细的介绍了 Firefox 扩展的开发流程。

使用 XUL 实现浏览器扩展 [(1)](http://www.ibm.com/developerworks/cn/web/wa-xul1/) 、[(2)](http://www.ibm.com/developerworks/cn/web/wa-xul2/)
