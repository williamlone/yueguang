Google Picasa相册虽然很好用，可是长期被封，现在，Google Picasa相册终于开始支持Https，这使得墙内可直接访问HTTPS版本的Picasa Web Albums了。

Picasa Web Album向用户提供了1GB免费图片存储空间，虽说是为Picasa设计的网络相册，其实Picasa Web Album完全可以脱离Picasa软件运行，直接用浏览器就可以操作。

为了更好的保护用户隐私，Picasa Web Albums终于也像网页搜索、Google Docs和Gmail一样推出了HTTPS的加密传输版本，用户只要访问 `https://picasaweb.google.com` 就可以正常访问加密版本Google Picasa Web Album了。
