今天换了一个CPU，型号是P4 3.0E，价格570元。本来想换个好点的，可惜我当初购买的主板超微P4SCE只支持这么大的CPU，记得两年前购买的时候，CPU是P42.4B（960元），主板用超微P4SCE（1550元），现在只用570就可以换个更好的CPU了，估计那时被宰了。

更换CPU还有一段小插曲，换上CPU后，我怎么检测，都是一个线程，没有两个线程，我还以为CPU被奸商骗了，不过从CPUZ上看又是支持“超线程（Hyper-Threading，简称HT）”技术的，这是咋回事呢？

后来去微软的支持网站上看了下，才知道要在Windows 2000里设置一下，具体设置方法如下：

|  |  |
| --- | --- |
| 1. | 单击**开始**，指向**设置**，指向**控制面板**，然后双击**系统**。 |
| 2. | 单击**硬件**选项卡，然后单击**设备管理器**。 |
| 3. | 双击展开**计算机**分支。请注意看当前的支持类型。 |
| 4. | 双击**计算机**分支下列出的计算机类型，单击**驱动程序**选项卡，单击**更新驱动程序**，然后单击**下一步**。 |
| 5. | 单击“**显示已知设备驱动程序的列表**”，单击**下一步**,然后单击“ **显示这个设备类别的所有硬件**”。 |
| 6. | 单击适当的计算机类型（除多 CPU 外与您的当前类型相符的计算机类型），单击**下一步**，然后单击**完成**。 |

设置后重启，终于看到两个CPU了。

启用超线程后，初步感觉不错，CPU的使用率大为下降，原先是高于50%，而且经常100%，而现在基本上在10%左右使用率，真没想到超线程的效果竟然这么明显，看的我真有点目瞪口呆了，不过具体还要多观察一下。
